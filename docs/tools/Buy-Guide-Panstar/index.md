# Panstar 注册与套餐选购指引

通过邀请入口注册后，按推荐表中的**地区、产品线路、配置和付款周期**选择套餐。产品直达链接打开后，也请核对页面实际选中的套餐。

## 通过邀请入口注册

[进入 Panstar 邀请注册页面](https://panstar.ai/register?aff=DCAD1VCH)

完成注册并登录后，进入顶部的**“云服务器”**。下图标出的顺序为：进入云服务器 → 选择地区 → 选择产品；继续向下选择具体套餐。

![Panstar 选购顺序：进入云服务器，选择地区，再选择产品线路和套餐](images/panstar-purchase-steps.png)

> 截图用于说明操作位置，其中香港 Pro 的配置、库存和价格属于截图当时的记录。购买美国或德国套餐时，请按下方对应说明选择，不能直接照选截图中的香港套餐。

## 美国精品套餐选购 { #panstar-us }

1. 打开[美国推荐套餐入口](https://panstar.ai/servers?regionId=6&productId=15&planId=393&cycle=1&aff=DCAD1VCH)。
2. 确认地区为**美国洛杉矶**，产品线路与推荐表中的 **CN2 / 9929 / CMIN2** 相符。
3. 对照原推荐配置：**1核768MB、300Mbps 带宽、512GB 月流量**；原记录价格为 **5.99美元/月**。
4. 如链接未自动选中产品，请手动按地区、线路和配置选择。若套餐下架或配置不一致，请返回推荐表或咨询客服确认后再购买。

## 德国9929套餐选购 { #panstar-de }

1. 打开[德国推荐套餐入口](https://panstar.ai/servers?regionId=7&productId=21&planId=236&cycle=1&aff=DCAD1VCH)。
2. 确认地区为**德国**，产品线路为 **9929**。
3. 对照原推荐配置：**1核1GB、1000Mbps 带宽、1024GB 月流量**；原记录价格为 **6.99美元/月**。
4. 如链接未自动选中产品，请手动选择对应地区与线路，并核对库存和配置。

## 优惠与订单核对

- 在[官方优惠活动页面](https://panstar.ai/activities?aff=DCAD1VCH)查看当前适用的优惠，按页面说明领取或填写优惠码。
- 按自己的需要选择系统与付款周期，核对右侧订单详情中的地区、产品、配置、流量及最终应付金额。
- **价格、库存、线路名称和优惠可能调整，以结算页面实时信息为准。** 本指引沿用本站已有推荐资料，不代表实时库存确认。
